# Sprint Report: Internal MVP readiness check

日期：2026-10-11

## 目标

为公司内部 5–10 人局域网使用提供一个只读的一键就绪检查，减少人工检查端口、前端、API 和代理状态的成本。

## 实现

新增 `scripts/check-internal-mvp.ps1`，检查：

- 关键源码和前端入口文件是否存在；
- API 和前端端口是否监听；
- API live、ready、前端首页和前端 API 代理是否返回 HTTP 200；
- 可选 LAN 地址是否能访问前端。

脚本不会启动或停止进程，不执行迁移，不读取或打印 `.env`，不调用 Provider。

## 验证

使用异常测试端口运行脚本，确认未就绪时返回非零退出码；使用 PowerShell 解析器验证脚本语法。

PM 复验：PowerShell 解析通过；使用未监听的 `65530/65531` 端口运行时正确返回非零退出码并报告 6 项失败。真实局域网地址和正式服务状态需在部署主机上运行同一脚本确认。
