# 站点视频风格调研（2026-07-30）

## 结论

这 8 个站点应作为“品牌风格层”接入，而不是替代视频模板或服装事实。模板决定视频类型和镜头骨架，服装素材决定人物、款式、颜色、面料、印花和文字事实，站点风格只影响动作表达、场景气质、镜头距离、节奏和商品呈现重点。

当前研究形成的是第一版 `research` 配置，不足以直接激活付费模板。3 个站点（NerdyWave、PageWings、GoodNurseLife）对自动化请求返回 403，已明确标记为受限证据；后续收到站点详细调研或可访问的公开素材后，只需提升对应 profile 的版本和证据等级。

## 研究方法与证据等级

- 站内采样：读取首页标题、描述、导航、主题分类、产品名称、字体、主色、图片/视频标签和公开社媒链接；采样日期为 2026-07-30。
- 视频参考：使用 YouTube 公共搜索结果页，记录可见的标题、时长/播放信息和链接。当前环境可以读取结果页，但代表性 Shorts 播放窗口显示“视频无法播放”，因此动作结论分为“可见线索”和“专业扩展”，不把未观看内容写成事实。
- `verified_site`: 首页和页面样式可直接观察。
- `restricted_site`: 站点返回 403，只记录用户提供的品牌标签和受限事实。
- `video_index`: 来自公开搜索结果标题/缩略图的动作参考。

- 来源：[首页](https://www.geeksoutfit.com/)，公开入口：[Instagram](https://www.instagram.com/geeksoutfitstore/)、[TikTok](https://www.tiktok.com/@geeksoutfitstore)、[YouTube](https://www.youtube.com/channel/UCYftwHKqZQuA9BDRUaatzaA)、[Pinterest](https://www.pinterest.com/Geeksoutfit_official/)。

- 禁止错配：不可使用高级宗教庄严感、医疗工作流或强烈恐怖惊吓；不要用过度快速转场掩盖印花。

## 接入程序的规则

1. `siteStyleProfile` 与 `videoTemplate` 分开版本化；profile 不能写入人物和服装事实。
2. 站点风格只允许控制 `preferredActions`、镜头距离、运镜、节奏、商品呈现重点和禁用错配。
3. `draft/research` profile 与 `draft` template 都不能进入真实付费提交；编译器在开发测试中可显式 `allow_draft=True`。
4. 每个 profile 保留 `sourceUrls`、`retrievedAt`、`evidenceLevel`，后续详细调研直接升版本，不覆盖旧配置。
5. 动作差异必须来自受控动作库和模板兼容矩阵，不能用“随机发挥”扩大动作幅度。
