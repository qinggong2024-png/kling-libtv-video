## 真实联调前置条件

以下条件不阻止离线开发，但未满足前不得宣称真实生产闭环通过：

1. **Docker Engine**：当前 Docker Desktop Engine 未响应。启动后才可执行 PostgreSQL/MinIO 容器、在线迁移和对象存储集成测试。
2. **OpenAI**：当前未注入 `OPENAI_API_KEY`。注入后须用真实 Responses API 请求验证账号拥有 `gpt-5.6-sol` 权限，并验证结构化输出、延迟和 Token 指标。
3. **LibTV 真实素材**：当前不执行付费生成。用户提供素材后，按单用户、单并发 canary 逐级验证，不得跳过积分、UNKNOWN 和重复提交门禁。

## 开发约束

- 第一阶段默认 `LIBTV_ADAPTER_MODE=fake`；
- Real Adapter 只调用官方 `libtv` CLI，不构造 LibTV HTTP 请求；
- `libtv node --run` 由 CLI 阻塞到终态，调用方不添加 timeout 或额外轮询；
- PostgreSQL 是唯一事实源，Redis 不进入第一阶段核心路径；
- 上传素材成功物化到 LibTV 后删除，服务器成品保留 7 天，不生成 ZIP；
- PostgreSQL、MinIO 和 Runner 管理接口不得暴露到公网；
- 当前电脑仅用于开发和 1–2 名用户 MVP，稳定后通过 SSH 发布到长期在线 Windows 主机。
