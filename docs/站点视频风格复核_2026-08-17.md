# 站点视频风格复核（2026-08-17）

## 范围与方法

- 使用用户指定的 Chrome Playwright MCP 直访 12 个已登记官网，读取可见首页、导航、商品标题、公开社媒入口、字体和主色。
- 结合 `docs/action-library/collection_batch_001.md` 中已完成人工抽查的官方视频观察，区分站点事实、动作证据和保守建议。
- “魔法站点”没有 URL、官方素材或样片，不进行名称联想，继续保持 `draft / restricted_site`。
- 站点可访问不等于真人动作已验证。缺少合格真人穿着样片时，只补充视觉与商品边界，不升级动作结论。

## 生产边界

1. NerdyWave 与 PageWings 只使用现有动作库中的受控动作，不因本次激活新增动作原子。
2. PageWings 的书本关系镜头必须由输入画面中的真实书本触发；无书时不得新增书本或眼镜。
3. GoodNurseLife 只能作为研究草稿使用；不得从职业主题推导听诊器、针具、诊疗操作或制服替换。
4. OrionRide 本轮访问受限，保留旧证据但不提升结论强度。
5. 所有站点风格仍服从商品真实性、服装结构、文字可读性和已验证动作能力门控。
