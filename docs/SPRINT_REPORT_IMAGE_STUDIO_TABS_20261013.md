## 发现与限制

- 统一的是上传交互，生成继续遵守原后端固定参考顺序：图1到图6依次映射 `model.front / product.front / product.back / model.back / product.side / model.side`。移动或删除图片后重新映射该顺序；未编辑的旧素材保持原角色数据。
- 现有 fusion 仍按正面和背面规则生成，正面使用前两张，背面沿用第三/四张及既有背面推断设置；未实现任意多图同时参与一次通用编辑。第五/六张仍保留为原侧面角色，不新增 Provider 使用方式。
- 当前接口至少需要两张参考图。Nano Banana 最多 4 张，GPT 最多 6 张；超限会阻断提交，切换模型不静默删除素材。预估数量继续由原任务摘要计算，可能包含正背面输出。
- 文生图仍仅可保存创意草稿，生成按钮禁用；未虚构当前后端不支持的纯文本生成能力。
- 草稿继续使用原 450ms 保存防抖，刷新恢复验收等待“草稿已保存”。
- 502 运行环境问题独立于本轮，未修改 proxy、服务配置或重启服务。
- 精确滚动恢复仍是全站浏览器检查中的未通过项；测试通过不替代产品方向、上线或真实生成质量验收。
