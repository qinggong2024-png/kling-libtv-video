# 衣影工坊第二轮设计输入

日期：2026-10-09。状态：探索样稿，未替换正式 Design System。

## 用户反馈与共同目标

第一轮被用户评价为“都很机械，没有大厂成熟度的美观简洁的感觉”。用户允许自主检索其他品类的优秀设计，并认可使用 Linear 的秩序、Apple 的克制、Adobe 的工具控件、Notion 的渐进披露作为参考。认可的是研究与设计方法，不是对新页面的最终视觉验收。第二轮因此保留三个可比较的实际原型，不默认选定其中之一。

产品仍是跨境服装广告素材生产工作台。用户在日常工作中整理素材、配置模板与创意、提交生成、查看阶段、检查与审核结果。新外观应该让必要输入和当前行动更容易识别，减少参数墙、边框墙和粗重标题带来的压力，同时不能让低对比文字或隐藏控件牺牲操作准确性。不同页面需要共享一套基础视觉语言，不再靠各自的颜色来识别功能。

## 内容、尺寸与实现边界

三个方向均保留同一组示例图片、上传/排序/删除/放大、人物参考、模板与配方、自定义创意、高级参数、时长与数量、明确确认及结果状态。尺寸统一验证 1440×900、1102×900、1024×768、768×1024、390×844。原型使用本地 HTML/CSS/JS，复用既有本地交互模型，浏览器不需要发出 HTTP 请求。素材只作参考图与样稿封面，不代表真实生成的视频。没有真实 Provider、计费、认证或审核接口。

字体选择采用现有本机 Segoe UI Variable / Segoe UI / Microsoft YaHei 候选栈，字体层级通过大小、字重、行高、留白表达，不使用负字距。颜色以白、灰、石墨为主；主动作使用深石墨，状态仍由文字和图标表达。按钮采用统一圆角，工具操作弱化背景，输入使用轻底色而非密集边框。正式字体文件、自托管方式及实际字形覆盖尚未验收。

## 方向差异

- A 安静工作台：左侧导航、白色连续工作区、平衡的素材与创意双区，适合持续生产；减少区块容器，通过留白建立层级。
- B 工具面板：素材获得较宽空间，必要配置集中到右侧局部 Inspector；模式在设置区前部，低频设置折叠。Inspector 不作为装饰卡片，而是独立的局部编辑边界。
- C 阶段流程：水平导航、三步准备过程，素材、创意、提交分阶段展示；降低同时需要理解的信息量，代价是增加切换。属于待选择的布局探索，不擅自覆盖现有双区规范。
