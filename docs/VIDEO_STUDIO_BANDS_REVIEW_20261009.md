# Video Studio 纵向布局修订依据

日期：2026-10-09；状态：Checkpoint 1 待人工验收。

## 问题与判断

用户指出上一轮“跟原来没有明显差别”。实际浏览器已确认是更新版，问题不是缓存：左右素材/表单的整体结构仍在，可选主体三块空上传位占据固定高度。仅合并分镜归属不足以改变层级。

本轮改变操作区结构，不引入新品牌方向：素材整理在上，创意配置随后，统一提交在下，之后才是任务与结果。素材上传、排序、删除、检查仍在同一处。静态大图没有持续编辑功能，继续按需打开。

## 取舍

- 素材区是工具栏和实际缩略网格；每图轨道 104–128px。七图桌面可同排，窄屏换行，无强制横向滚动。
- 可选主体默认只显示一行；展开编辑，收起保留状态及摘要。种子参考图存在时默认展开，避免隐藏已带入的必需检查内容。
- 创意区内部桌面并列模板与生成方式，保持真实模板限制、配方 Drawer 与高级折叠。
- 不使用固定付费按钮覆盖内容，不改变 API、幂等键、UNKNOWN、批量恢复、认证、来源 ID 或审批能力。
- 标准图片转视频表单继续原布局，不引入 Studio 折叠。
- 未采纳其他任务新增的三方向全站原型，不将探索中的品牌、字体或布局当作已批准方向。

## 验收

检查五宽度、空/两图/七图、拖拽/键盘/删除/大图、主体展开收起与选择保留、提交保护、状态、结果播放和任务深链接。1440×900 两图+历史主体收起+自动配置、无历史任务时，提交可见且结果区起点处于首屏；不要求全部结果或任意素材/任务数量都在首屏。

首轮结果区仍在首屏外，原因是上传动作 flex 换行和旧全局按钮尺寸。已修复局部工具栏样式并复测，不通过删掉验收断言来掩盖问题。初轮批量退出按钮启用断言遇到状态提交时序，后续验证按可观察的启用状态等待。

没有真实用户计时或点击对照；本轮不声称完成正式产品研究或效率改善。工程验证后仍等待方向验收，停在 Checkpoint 1。
