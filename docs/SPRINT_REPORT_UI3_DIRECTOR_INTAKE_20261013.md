# Sprint Report：UI-3 Director Intake 与方向推荐动线

日期：2026-10-13
本轮范围：Director Studio 首屏输入工作区、真实分析后的方向推荐入口和响应式视觉动线

## 完成

- 将导演台首屏收敛为上传素材、品牌归属、品牌选择、材质和视频类型输入。
- 增加真实阶段进度：准备输入、AI 分析、选择方向、输出提示词。
- 只有服务端返回 `snapshot.plan.directions` 后才显示方向卡片。
- 分析完成后自动滚动并将焦点移到 AI 推荐方向区域。
- 方向未产生前隐藏方向区和 Production Package，避免默认内容造成误导。
- 移除首屏独立“分析准备”卡片，避免在用户上传和填写必要输入前增加第二个工作区域。
- 将首屏改为完整输入工作区：左侧上传商品图，右侧填写商品名称、品牌归属、衣服材质和视频类型。
- 保留唯一的“创建任务并分析”主操作，并将其放在必要输入之后、可选字段之前。
- 将创作目标、目标受众和备注收进“更多创作约束”折叠区，隐藏实现层说明。
- 去掉 Product Intake 和 AI 推荐方向标题中的重复面板序号，只保留顶部流程步骤编号。
- 品牌选择复用现有 `getSiteStyleProfiles()`，过滤已退役品牌。
- 品牌模式要求已选择品牌；通用模式继续支持。
- 保留当前离线 Fake、审核、恢复、Production Bridge 和 Provider submission disabled 语义。

## 修改

- 修改 Director Studio 前端结构和样式。
- 为前端 Brief 展示模型增加可选材质和视频类型字段。
- 不修改 `frontend/src/api.ts`、后端 API、Creative Workflow 状态机或 Provider。
- 视频入口仅作为明确的待接入占位；当前导演分析接口仍只支持图片。
- 新增品牌必选规则测试。

## 发现问题

- 当前后端导演任务创建接口只接收商品正面图片，不接收视频。
- 当前品牌、材质和视频类型属于前端项目 Brief 展示信息，尚未进入导演分析 API 请求。
- 因此本轮没有宣称视频分析或这些字段已影响服务端推荐。
- 工作树存在其他窗口的后端未提交修改，本轮未覆盖、回滚或同步这些文件。
