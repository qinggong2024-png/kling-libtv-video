# Sprint Report: 上装视频提示词优化

日期：2026-10-10
范围：内容库动作筛选、自动视频 Prompt 编译、目录编辑门禁；不改前端。

## 完成

- 商品范围固定为上装。走动、坐姿与背景中的已有下装可以作为人体/空间证据，
  但裤装、裙装、鞋履、腰线与台阶卖点不进入上装自动动作推荐。
- 历史动作和任务不删除。productFocus、历史 ID、能力前提与品牌基础动作共同参与范围筛选。
- 新增 motion_to_rest；收尾沿用输入姿态和持物关系，不新增走动、手势或坐站转换。
- 扣件展示保持原开合状态；背面走动仅展示真实参考中的上装后身；衣摆与印花停留不再要求裙摆或额外推拉镜头。

## 修改

- 新增 ShotMotionContract：进入状态、单主动作、镜头、环境响应、退出状态与锁项。
  契约随 variant_seed 持久化，保留版本和商品范围。
- 镜头采用 locked / push_in / pull_back / lateral_follow 白名单；
  精确匹配旧池别名，未知或复合运镜回退 locked，保留输入机位，不凭文字新增低机位。
- 镜头只允许低能量单轴运动。去掉默认叠加的自然手持；
  环境只允许已有上装随主体动作响应，不生成风、烟、粒子、道具或新的光线。
- 无能力证据也使用单主动作选择器。动作池没有可用项时稳定收尾，
  不再把多个备选动作拼成连续指令。
- 微动作仅保留已验证的低幅视线/表情动作；走动、转身、背面或视线主动作不叠加微动作。
  主动作与微动作必须在同一素材证据集中同时满足前提。
- 当前共享动作契约覆盖所有分镜，因此使用各分镜证据交集；
  不把单张图支持的动作传播到不支持它的另一张图。
- 保留既有 confirmed / denied / unknown 的明确证据规则；
  不引入自动视觉分析，也不把推断或图片文件名当成已观察事实。
- 明确商品/身份锁项；常用负面项去重并保留皮肤质感防护。
  压缩优先删学习/风格冗余，保留已选动作、镜头、收尾和商品锁项；不足则拒绝，不截断。
- API 拒绝 conditional + 空前提，也拒绝用 low 风险或空列表移除既有能力门禁。
  老客户端不传 productFocus 时保留已有范围。
- 新自动编译器版本 fixed-template-v4-upper-garment；
  自定义 Prompt 仍原样绑定参考，历史任务的已提交 Prompt 不重编译。

  覆盖新规则、动作、品牌、模板、目录、领域合同、反馈、幂等及配额。

  验证 3072 字符上限、单主动作/可选微动作、镜头预算和上装范围。

  不覆盖用户前端、其他文档与未跟踪工件。
- main 局部推广及独立验证结果在本报告后续追加。

## 发现问题

- 原 Prompt 压缩可能删掉动作正文但保留已选择动作记录，现已修正。
- 原候选动作可能在未知素材时串联，原跨图能力汇总可能把单张证据传播到全片，现保守收紧。
- main 动作库较测试基线少扣件与背面走动定义，推广时只补两项必要上装条目及扣件能力枚举。
- 这是确定性编译和门禁验证，不是生成画面真实性、销售转化率或费用收益验证。
  单轴限制是提交 Prompt 的约束，不是视频模型必然遵循的物理保证。
- 不部署、迁移、重启、读真实 .env、写生产数据或调用付费模型。无前端改动，不续报浏览器验收。
