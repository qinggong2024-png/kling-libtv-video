# Creative OS UI-2 Refinement Specification

日期：2026-10-12
范围：前端产品壳、导演布局、Studio 视觉一致性与响应式。
授权：用户确认进入 UI-2，并要求减少导演台的项目入口。

## 设计方向

使用者为需要连续完成商品广告素材制作、选方向和审核的一线创意人员。页面首先回答当前正在制作什么、有哪些输入、下一步可执行什么。

- 领域词汇：商品正面、创作意图、方向候选、锁定生产包、首帧、分镜、审核证据、交付资格。
- 颜色来源：白色工作台、中性灰界面、黑色文字、蓝色操作焦点、绿色已记录证据、琥珀色待审核、红色错误。素材保留自身颜色。
- 产品特征：商品输入、方向选择、生产包沿同一动线组织；媒体不承担装饰用途，证据状态不冒充生成进度。
- 避免重复导航、项目管理首页、浮动卡片套卡片、大面积渐变和参数统计墙。
- 空间：208px 桌面导航；1120px 制作内容上限；4px 基础间距；操作控件至少 44px。
- 字体沿用现有栈，字号固定，字距为 0；正文、标签和状态通过字重与颜色分层。
- 层次优先使用连续布局、留白和细分隔线。方向候选作为独立重复项保留卡片。

## 导航与项目上下文

主导航收敛为图片工作室、视频工作室、任务中心、素材库。

智能导演保留在图片工作室内部的模式切换中。不建立第五个产品工作区，不新增路由引擎或改动导航状态所有权。

项目只在 Studio / 任务 / 素材页的紧凑上下文条保留一个进入当前工作区的入口。工作区页面自身不再重复展示上下文条。项目名称编辑和规划记录使用带 tooltip 的图标按钮。

项目、记忆、工作区的既有 pane 深链接保留；从主导航移除入口不删除相关页面或持久化能力。管理权限、设置、帮助及账号操作保留。

| 链接 | 兼容行为 |
| --- | --- |
| `?view=images` | 既有图片工作室，模式行为保留 |
| `?view=images&pane=director` | 图片工作室内的智能导演 |
| `?view=make` | 既有视频制作页 |
| `?task=id` | 既有视频任务详情抽屉 |
| `?view=records` | 任务中心与原有筛选、搜索、返回行为 |
| `?view=library` | 既有内容与主体库 |
| `?view=make&pane=workspace` | 当前创作工作区 |
| `?view=make&pane=projects` | 兼容的当前项目展示 |
| `?view=make&pane=memory` | 兼容的规划记录 |
| `?project=id` | 导航继续保留查询引用，不声明新增后端项目管理 |

主导航操作复用原有 switchView；任务中心默认进入既有全部任务。工作区生产路径中的审核入口保留原有 review surface / attention 行为。

## 页面与响应式

工作区顺序为项目名称与状态 → 下一步行动 → 创意概览 → 生产路径 → 已存在生产包。所有状态继续由现有 workspacePresentation 派生，不建立新的工作流状态。

导演台：

- 1440px：输入、方向、生产包三栏。
- 1024px：输入与方向并列，生产包位于其后。
- 768px：收起桌面导航，保留紧凑工作区和底部导航。
- 390px：输入 → 方向 → 生产包依 DOM 顺序纵向排列。
- 数字序号不得换行；商品预览使用 contain；长名称和哈希换行或明确截断。
- Fake、只读、预检和不可交付声明继续保留。

移动端取消第二条横向产品导航，使用一套底部导航。长项目名称不推挤状态和其他操作。

动效沿用既有基础组件的浮层与操作反馈，导航不使用位移，按钮不使用大面积光效。新加交互反馈使用约 120ms 色彩变化；新增控件尊重 reduced-motion。已存在的业务 guard 不变。

## 改动边界

允许修改 App / AppShell 的导航呈现、CreativeWorkspaceView 的 JSX 排布、ImageStudio 标题、directorStudio.css 与全局壳样式，以及对应浏览器验收脚本。

保持 API、Task State、Creative Workflow Contract、生成、轮询、恢复、通知、上传及授权处理不变。DirectorStudio 的恢复逻辑、Provider 和计费相关开发属于其他工作包，本阶段不修改或一并提交。

ImageStudio 无条件挂载约束继续保留，非当前页的实例只隐藏，避免中断后台轮询与通知。

## 验收

执行 build、lint、unit、既有 UI smoke、隔离视频与导演流程，以及新增四视口壳检查。验证项目编辑的 Escape / 焦点返回、下一步首屏可达、真实媒体元素加载、长名称、历史链接、back/forward、任务抽屉与 records 滚动恢复。

只在隔离 fixture 中提交测试生成操作；不得访问真实付费 Provider。记录浏览器版本、源码哈希和截图；本地 UI-2 验收不代表正式运行环境或生产链验收。

测试分支验证后将本次补丁同步到实际 main，并独立验证。提交中不夹带其他窗口的未提交修改。构建产物与测试缓存放在仓库外。

完成后停在 UI-2 人工体验验收，不自动部署、进入真实 Provider 或扩展 AI 能力。
