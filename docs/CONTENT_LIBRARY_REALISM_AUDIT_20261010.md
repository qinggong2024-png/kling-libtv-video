# 内容库真实性审查记录

- 日期：`2026-10-10`
- 范围：品牌风格画像、动作库、动作能力筛选、内容库编辑接口
- 目标：筛掉会让生成视频补造脸部、身体关系、道具或空间事实的内容

## 结论

当前内容库没有发现应直接删除的危险品牌风格。已有资料明确排除了武器、危险训练、凭空新增自行车/医疗器械、遮挡核心印花、夸张身体动作和未经完整复核的视频动作。

发现并已收紧三项动作：

| 动作 | 风险 | 处理 |
| --- | --- | --- |
| `controlled_gaze` | 原先未要求脸部清晰，可能在裁切或脸部不可见时补造眼神 | 增加 `face_visible`、`face_gaze_adjustable`，改为 `conditional` |
| `head_shoulder_tilt` | 原先未要求头肩轮廓清晰，可能造成颈部、肩线和脸部变形 | 增加 `face_visible`，改为 `conditional` |
| `asymmetric_pause` | 原先未要求下装和站立空间，近景或半身素材执行肩胯错位容易产生身体结构假感 | 增加 `lower_garment_visible`、`standing_space`，改为 `conditional` |

## 保留但必须满足前提的内容

- 背面展示、走动、衣摆/袖口/领口整理、坐姿、道具、同伴和门口动作均保留；它们已有能力约束，未知素材不会通过动作筛选。
- 骑行、训练器械、医疗器械、危险道具和文化角色化表演不进入无道具默认动作路径。
- `goodnurselife` 仍为 `draft`，没有合格真人穿着证据时不进入正式自动生产。
- 品牌风格中的 `forbiddenMotion` 与 `forbiddenMismatches` 会进入自动模式负面提示词；内容库中的环境只作为偏好记录，不会凭空新增场景。

## 工程门禁

- 内容库接口拒绝没有能力前提的 `conditional` 新动作。
- 新增审计测试覆盖脸部/身体证据缺失时的动作排除。
- 本记录只说明内容与筛选规则，不代表真实 Provider 生成质量或正式版已部署。
