# 正式版与测试版隔离

| 环境 | 代码 | Web | API | 数据与素材 |
| --- | --- | --- | --- | --- |
| 正式版 | `C:\Users\Reel\Documents\libtv-production` 的 `main` | `5173` | `8000` | 正式工作树内的 `var` |
| 测试版 | `C:\Users\Reel\Documents\libtv自动化生成` 的 `codex/testing` | `5175` | `8001` | `var\test` |

正式版只运行已经提交到 `main` 的代码。功能开发和 Codex 验证只能在测试版目录进行。

启动测试版：

```powershell
powershell -ExecutionPolicy Bypass -File scripts\start-test-stack.ps1
```

测试版启动器会强制使用独立数据库、素材目录、Cookie 和日志，并关闭付费生成。验证通过后，先提交并合并到 `main`，再从正式工作树重启正式服务。
