## 本批先解决的问题

用户新增的四个站点不是四种简单审美：

- **骑行**是使用场景，OrionRide 还包含复古骑行艺术、彩色图形和生活方式服装。
- **健身**是使用场景，IronPandaFit 同时包含力量文化、幽默口号、洗水复古和运动街头。
- **东京**是文化与主题入口，Tokyo-Tiger 实际横跨动物、食物、城市、幽默、木版画式图形、球衣和夏日衬衫。
- **大码**是尺码和目标人群，BoldOversize 的审美包含复古、幽默、塔罗、运动、动物、节日等。

动作库因此继续共享基础动作，只在品类、场景条件、参数权重和排除规则上区分。

## 镜头和节奏

| 场景 | 推荐结构 | 节奏 |
| --- | --- | --- |
| 通用商品片 | 正面中全景 → 三分之四 → 图案/结构近景 → 完整商品确认 | 每姿态 1.5–3 秒 |
| 骑行情境片 | 侧面骑行 → 后方驶离 → 车旁背面中近景 → 推车/步行 | 动态片段 1–2.5 秒，背图 1.5–2 秒 |
| 健身情境片 | 低风险训练切片 → 正面站定 → 图形近景 → 自然恢复 | 训练切片 0.8–2 秒，商品确认至少 1–1.5 秒 |
| 东京图形服 | 正面图案停留 → 轻微三分之四 → 可选图案中近景 | 每有效姿态 1–1.8 秒；复杂图案更慢 |
| 大码版型片 | 正面全身 → 自然错位重心 → 小步 → 轻微三分之四 | 连续自然，约 3–5 秒一阶段 |

## 通用与特有

通用动作包括自然站定、重心变化、一步进入/退出、三分之四转体、背印停留和无遮挡图案确认。球衣、宽松上衣、长裙等差异应由品类条件控制。

站内强条件只有 OrionRide 的自行车/户外路径。IronPandaFit、Tokyo-Tiger 和 BoldOversize 暂时都没有独占人体动作，它们分别通过健身编辑组合、文化图形可读性、身体中立执行规范来区分。

## 安全与质量红线

- 不从运动站自动添加自行车、杠铃、拳击手套、训练带、头盔或护具。
- 不收录危险越野、极限负重、力竭、疼痛、倒地或器械教学动作。
- 不把日本文化简化成鞠躬、武士、动漫角色扮演或霓虹赛博。
- 不把大码展示写成吸腹、遮腹、缩肩、踮脚、极端侧身或胖瘦对比。
- 不用手、包、外套、器械、字幕或箭头遮挡核心图案。
- 未直接完整播放的内容不进入动作事实库。

## 升级结论

本批不新增生产级动作。`controlled_front_approach_to_settle`、`relaxed_staggered_weight_shift` 和 `small_step_front_hold` 应先与已有 `controlled_walk`、`stance_shift` 去重；骑行动作与 `bilateral_neckline_settle` 仍缺独立来源和生成回放。
