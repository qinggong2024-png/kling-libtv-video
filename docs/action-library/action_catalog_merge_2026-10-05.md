# 动作库整理合并记录

- 日期：`2026-10-05`
- 目标：减少同义动作重复展示，同时保留历史配置、反馈记录和外部调用的兼容性。

## 已合并

| 旧动作 ID | 标准动作 ID | 合并原因 |
| --- | --- | --- |
| `chest_print_pause` | `print_detail_pause` | 两者都只要求已有正面图案可见，执行结果都是稳定的图案/文字可读停留；胸前文字属于印花展示的具体场景，不需要独立动作原子。 |
| `eye_contact_neutral` | `controlled_gaze` | 两者都是小幅视线移回镜头后短暂停留，不改变身体姿态；中性表情由风格画像控制。 |
| `cool_detached_glance` | `controlled_gaze` | “克制、冷感”属于表演风格，不是独立运动路径；保留为风格画像中的表达规则。 |

旧 ID 仍作为兼容别名接受，但不会再作为独立动作出现在动作库列表中。动作筛选、内容库动态覆盖、风格画像和学习反馈都会先归一化到标准 ID。

## 保留原则

有独立商品结构、空间方向、环境或安全前提的动作继续保留，不按名称相似度强行合并。

## 兼容实现

- 标准动作定义仍在 `backend/src/libtv_agent/templates/motion_actions.py`。
- 别名表为 `ACTION_ALIASES`。
- `compatible_action_ids()` 和提示词编排会自动归一化旧 ID。
- 数据库中的历史动作覆盖项也会按标准 ID 合并，避免旧配置重新制造重复卡片。
