# 衣影工坊界面视觉方案 · Checkpoint 1

状态：保留既有品牌的 Video Studio 细化候选；尚未通过人工方向验收。不采用或覆盖其他任务未选定的三方向原型。

## 产品界面意图（interface-design）

用户：在日常广告生产中整理服装与人物素材、配置生成、处理失败、检查并审核结果的创意人员。界面应像明亮且安静的素材工作台，动作清楚、结果真实，适合持续操作。

领域：服装轮廓、面料细节、人物一致性、分镜次序、镜头动作、模板配方、成片审核。

自然色彩世界：摄影棚白、接触表浅灰、场记板石墨、牛仔蓝、面料中性色；语义绿/琥珀/红只用于状态。

特征：同一个分镜接触表同时承载顺序、完整 contain 预览、原文件名、删除与键盘排序；主体摘要、模板画幅/数量、提交数量继续保持真实来源。素材是主角，界面提供生产秩序。

替代三个默认模式：统计墙 → 当前制作任务；层层浮动卡片 → 连续工作区/必要分隔；艳色和悬浮动效 → 单一品牌蓝/短时操作反馈。

| 维度 | 候选值 | 用途与依据 |
| --- | --- | --- |
| 基础表面 | 白 #FFFFFF；输入淡底 #F7F8FC | 摄影棚与接触表，中性色不抢服装图 |
| 字色 | #26272C / #484C56 / #5D6069 | 主要、说明、元信息层级，辅助文字满足对比 |
| 主操作 | 既有 #2563EB / hover #1D4ED8 | 保留品牌，蓝色集中用于操作、选择和焦点 |

| 字体 | 既有 Inter、Noto Sans SC、Microsoft YaHei 回退栈 | 中文操作准确，未添加远程字体依赖 |
| 字级 | 标题 26/22；区块 16；输入 14；元信息 12/13 | 字重650/500/400与色阶共同形成层级；字距0 |

UI/UX Pro Max：使用本机数据库查询 design-system、color、Chinese typography、UX feedback/reduced-motion/focus、React focus/errors。综合生成结果中的 fashion rose、Kinetic Brutalism、营销 Hero 和跑马灯不符合生产工具，不采用。采用 `Chinese Simplified` 字体支持、现有蓝色可读组合、44px触达、可见焦点和真实异步状态建议。最终以产品文档与当前品牌为上位约束。

## 核心页面与交互

Video Studio：素材整理 → 创意配置 → 时长/数量/付费提交 → 真实阶段 → 结果。桌面与手机保留 DOM 顺序。两图不膨胀成永久大画布，七图换行；可选主体保持收起与状态保留；完整配方按需打开。

只有 Video Studio 应用新的视觉作用域 `.app-shell--video` 与 `studioRefinement.css`。共享 Modal、Button 和焦点的缺陷修复会惠及既有使用处，不据此宣称其余页面已完成视觉升级。

键盘生成方式使用方向键/Home/End、单一Tab入口。原生弹窗焦点隔离、Escape与焦点恢复，保存进行中遵守现有禁止关闭合同。原生素材预览按钮继续支持 Enter/Space。

减少动态效果：取消旋转、缩放和移动，保留短时色彩反馈；阶段文本/数值始终可读，未知结果不自动重试。手机帮助使用桌面既有真实文字，不新增业务指引或价格承诺。
